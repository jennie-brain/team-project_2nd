## 0. 최종 판단

**A(미래지출-카드혜택 자동 연결)와 C(실행 완주)는 사실상 공동 1위다.**

| 모수 | 1위 | 2위 | 격차 |
| --- | --- | --- | :---: |
| **SOM 버전**(낙관적 도달가능성) | **A** (DOS 3.04) | C (3.00) | **0.04** |
| **SAM 버전**(보수적 도달가능성) | **C** (DOS 2.40) | A (2.32) | **0.08** |

**모수를 바꾸면 순위가 뒤바뀔 만큼 붙어 있다는 것 자체가 "공동 1위"라는 결론을 어떤 모수를 쓰든 지지한다.** 사분면 배치는 두 버전 모두 동일하다 — **A·C 최우선 / B 시장주도 / F 니치 / D·E 후순위**.

**두 번째 결론: F는 AOS만 보면 A·C와 동급이지만 시장 가중 후 4위로 밀린다.** AOS 3.2(Q1 혁신기회)인데 DOS는 SOM 1.50 / SAM 0.90으로 **니치**다. 그래서 **F는 별도 기능을 만들지 않고 "이벤트 선택 단계를 두지 않는 것"만으로 대응**한다.

**세 번째 결론: C는 6개 후보 중 유일하게 Importance 근거가 🔵 공식 통계**(금감원 민원 +88.4%)다. 나머지는 전부 팀 추정 🟡이다. **근거가 가장 강한 기회에 대응 기능이 없다**는 것이 [08](08_Value_Proposition.md)의 핵심 문제로 이어진다.

> ⚠️ **AOS와 DOS는 같은 척도 위에 있지 않다.** 2-1절 각주 참조 — 순위 비교는 각 표 안에서만 유효하다.

## 2. 산식·계산

### 2-1. 두 공식

```
AOS = Importance × (1 − Satisfaction / 5)
DOS = (Importance − Satisfaction) × Market Relevance
```

> ⚠️ **원본 문서가 두 개의 다른 기회점수 공식을 쓴다.** AOS 절은 `Imp × (1 − Sat/5)`를, DOS 절은 `(Imp − Sat) × MR`을 쓴다. **원본 DOS 표의 12개 값 전부가 후자로만 재현된다** — 예: C SOM = (4−1) × 1.00 = **3.00**. 전자로 계산하면 3.2 × 1.00 = 3.20이 되어 원본과 불일치한다.
>
> **결과적으로 AOS와 DOS는 같은 척도 위에 있지 않다.** 순위 비교(A·C 역전)는 각 표 안에서만 유효하고, **AOS 값과 DOS 값을 직접 견주면 안 된다.** 채점자가 검산할 수 있는 지점이므로 이 각주를 지우지 않는다 → [10](10_Evidence_Inference_Assumption.md) U-11.

### 2-2. Market Relevance — 2요인 모델

```
Market Relevance ≈ normalize( 인원 비중(그 계층 / TAM) × 도달가능성 가중치 )
```

**왜 2요인인가** — 1차본은 *"SOM에 가까울수록 높게, TAM에 가까울수록 낮게"*라는 직관만 썼다. 다시 짚어보니 문제가 있었다: **SOM은 원래 TAM보다 인원수가 훨씬 작은 계층인데(SOM ⊂ SAM ⊂ TAM), MR을 "TAM 대비 순수 인원 비중(%)"으로만 계산하면 오히려 SOM(이서연 등)이 가장 낮은 점수를 받는다.** 이는 이미 확정한 우선순위(Q1 혼인 = 1차 표적)와 정반대 결론이 된다.

`가람/0819/DOS 분석 방법론.md` Rules 2번이 *"TAM-SAM-SOM(%)... 을 사용하거나, 시장 성장률, **채택난이도**, **확산성** 등을 추가로 고려해 평가"*하라고 이미 허용하므로, 이 조항을 근거로 두 요인을 곱했다.

| 계층 | 인원 비중(TAM 대비) | 도달가능성 가중치 | 최종 MR |
| --- | --- | --- | :---: |
| **SOM**(이서연·박서준) | 최소 — 혼인 연 48만 명의 하위 부분집합 🟡 | **최고** — 현재 실제로 겨냥 중인 Beachhead, 채널 지표(카드고릴라 140만·뱅크샐러드 130만) 존재 | 0.8~1.0 |
| SOM(김도윤) | 최소 — 혼인+이사 중복 부분집합 | 높음(Q1 요소가 주력) | 0.7~0.9 |
| SAM Phase 1(한지민·최유리) | 소 — 이사 대리지표 🟠 실수치 미확인 | 중간 — 2차 표적이나 채널 미확정 | 0.5~0.7 |
| SAM Phase 2(정하늘·오세훈·강민재) | 중 — 이벤트 비종속 확장 전체 ⚪ 추정치만 | 중하 — 로직 일반화 후 확장 예정이나 미실행 | 0.3~0.5 |
| TAM 전체(신은서·윤태호) | **대** — 카드 보유자 중 무작위 하위집합 | **낮음** — 특정 채널·세그먼트 전략 없음 | 0.2~0.4 |
| TAM 경계(조민아) | 대 — TAM 안이나 전환 실패 | 최저에 가까움 — 온보딩에서 이미 이탈 | 0.1~0.2 |
| TAM 밖(배정호) | 해당 없음 — 마이데이터 미이용으로 **자격 미달** | 0에 가까움 | 0.1 |

**핵심 논리 — "크지만 닿을 수 없는 시장은 관련도가 낮다."** 신은서·윤태호는 인원 비중(분모=TAM 전체)만 보면 가장 커 보이지만 이 Pain을 겨냥한 채널·세그먼트 전략이 없어 도달가능성이 가장 낮다. [04](04_TAM_SAM_SOM_Segment_Map.md)의 Q4("카드 갱신 일반군")가 "대상 아님"으로 판정된 것과 **같은 논리**다.

> ⚠️ 인원 비중의 "최소/소/중/대"는 KOSIS 실수치가 아니라 [04](04_TAM_SAM_SOM_Segment_Map.md)의 🟠/⚪/🟡 확정 전 상태를 반영한 **상대적 서술**이다.

### 2-3. 중앙값 계산

```
Importance   {5,4,4,3,3,4} → 정렬 3,3,4,4,4,5 → median = 4.0
Satisfaction {1,2,1,2,2,1} → 정렬 1,1,1,2,2,2 → median = 1.5
AOS          {4.0,3.2,3.2,2.4,1.8,1.8}       → median = 2.8
DOS(SOM)     {3.04,3.00,1.60,1.50,0.77,0.65} → median = 1.55
DOS(SAM)     {2.32,2.40,1.26,0.90,0.57,0.48} → median = 1.08
```

**사분면 기준점으로 평균이 아니라 중앙값을 쓴 이유** — 표본이 6개뿐이라 극단값(A의 4.0)이 평균을 끌어올린다. 다만 **표본 6개에서는 중앙값도 불안정하다**는 것이 이 방법론의 한계 3번이다.

### 2-4. MR 평균 검산 예시

```
A: (이서연 1.0 + 김도윤 0.9 + 한지민 0.7 + 최유리 0.7 + 정하늘 0.5) / 5 = 3.8/5 = 0.76 ✓
   DOS(SOM) = (5−1) × 0.76 = 3.04 ✓
C: (이서연 1.0 + 박서준 1.0) / 2 = 1.00 ✓
   DOS(SOM) = (4−1) × 1.00 = 3.00 ✓
   DOS(SAM) = (4−1) × 0.80 = 2.40 ✓
```

| 1위 | A (3.04) | **C (2.40)** | **✅ 역전** |
| 2위 | C (3.00) | A (2.32) | ✅ 역전 |
| 3위 | B (1.60) | B (1.26) | ✗ 동일 |
| 4위 | F (1.50) | F (0.90) | ✗ 동일 |
| 5·6위 | E · D | E · D | ✗ 동일 |
| **사분면 배치** | A·C 최우선 / B 시장주도 / F 니치 / D·E 후순위 | **완전 동일** | ✗ 동일 |

**민감도 분석의 결론 — 실행 순서를 정하는 판단은 모수 선택에 강건하다.** 흔들리는 것은 A·C 중 어느 쪽이 근소하게 앞서는지 하나뿐이고, 둘 다 최우선 사분면 안에 있다는 사실은 변하지 않는다.

### 5-2. AOS 단독 vs 시장 가중 후 — F의 이동

| 후보 | AOS 단독 판정 | 시장 가중(DOS) 후 | 해석 |
| :---: | --- | --- | --- |
| A | Q1 혁신기회 | 최우선 | 유지 |
| C | Q1 혁신기회 | 최우선 | 유지 |
| **F** | **Q1 혁신기회**(A·C와 동급) | **니치** | **고객 임팩트는 크지만 지금 닿을 수 있는 시장이 작다** |
| B | Q2 개선기회 | 시장주도 | 임팩트는 작아도 도달 가능한 층이 넓다 |
| D·E | Q4 과잉투자 위험 | 후순위 | 유지 |

**F와 B가 반대 방향으로 움직인다** — F는 임팩트 대비 시장이 작고, B는 임팩트 대비 시장이 넓다. **AOS만 봤다면 F에 자원을 넣고 B를 뒤로 미뤘을 것이다.** 두 점수를 함께 본 이유가 여기 있다.

### 5-3. 현재 대안 비교 — Satisfaction 채점의 근거

| 후보 | 시장의 대안이 존재하는가 | Sat |
| :---: | --- | :---: |
| A · C · F | **사실상 없음**(A는 과거 기준만, C는 오히려 방해, F는 전 산업 빈칸) | 1 |
| B · D · E | **부분적으로 존재**(B는 결과 금액만, D는 엑셀, E는 대안 자체가 없으나 니즈도 약함) | 2 |

**Satisfaction이 1인 세 후보가 그대로 AOS 상위 3위**다 — 이 방법론에서 순위를 만든 것은 Importance보다 **"현재 대안이 없다"는 사실**이었다.
