## 0. 최종 판단

**Fit 검사 결과: 6개 중 ✅3 · 🔶3 · 🔴0** (2026-08-20 후보 C 결정 반영 — 이전 판정은 1개 🔴).

**핵심 판단은 공동 1위 기회 C(실행 완주)에 대응 기능이 없다는 것, 그리고 그 공백을 기능이 아니라 측정으로 메운다는 것이다.**

| 방향 | C의 근거 |
| --- | --- |
| **정량** | C는 DOS(SAM) **1위**이고, Importance 근거가 6개 후보 중 **유일하게 🔵 공식 통계**(금감원 민원 +88.4%)다 |
| **정성** | 인터뷰에서 신은서·박서준 **둘 다** *"계산 근거는 있어도 실행 단계 지원이 부족하다"* |
| **여정** | CJM 완주 실패 4명 중 **2명이 실행 단계**에서 끊긴다(신은서=외부 마찰, 윤태호=내부 과부하 — **원인이 달라 해법도 둘이어야 한다**) |

그리고 브리프 차별점 **①실행 설계자**가 바로 이 기회를 근거로 세워진 축이다. **근거는 가장 강하고 기능은 비어 있다.**

> F-05를 좁힌 판단 자체는 합리적이다 — 상담사 화법은 서비스가 통제할 수 없고 대행은 규제·운영 리스크가 크다. 문제는 **좁히면서 대안 설계를 하지 않은 것**이었다.
>
> **2026-08-20 결정** — 대행 없이 가능한 4개 후보 중 **ⓐ 실행 완주율 지표 신설만 채택**했다(F-13). ⓑ만류 대응 안내·ⓒ실행 체크리스트·상태 추적은 **채택하지 않는다**(개입 권한이 없는 범위에서 측정만 한다). ⓓ단계 쪼개기는 F-07(Could)로 분리했다. **기능으로 메우지 않고 측정으로 사각지대를 드러내는 것**이 최종 답이다.

**North Star = 조합안 선택률(Payment Plan Selection Rate) ≥ 40% 🟡** — 외부 벤치마크가 없어 **팀 합의 임계치**다.

## 2. 산식·계산 — KPI 설계

### 2-1. North Star 산식

```
조합안 선택률 = 조합안을 저장·확정한 사용자 ÷ 결과를 열람한 사용자
                (단, "현재 조합 유지" 결론을 받은 사용자는 분모에서 제외)

집계 단위 : 사람 단위 (재계산 반복은 1로)
인정 기간 : 결과 열람 후 7일 이내 (코호트)
목표      : ≥ 40% 🟡 (팀 합의 임계치 — 외부 벤치마크 없음)
중단선    : Concierge Test에서 < 20% → "가장 큰 가정" 붕괴로 보고 피벗
```

**North Star 선정 이유 3개**

| 기준 | 왜 이 지표인가 |
| --- | --- |
| **행동을 잰다** | 화면 조회나 가입이 아니라 **"저장·확정" 클릭**이다. 가치 제안(*"계산을 대신해 결론 하나를 준다"*)의 직접 결과 |
| **나쁘면 내려간다** | 조합안 품질이 떨어지면 즉시 표시가 난다. **누적 가입자 수는 서비스가 망해가는 중에도 오른다** |
| **결정을 바꾼다** | 20% 미달이면 피벗한다 — 판단을 바꾸지 않는 지표는 지표가 아니다 |

> ⚠️ **분모 제외가 이 지표의 핵심 설계다.** Net Benefit 임계 미달 시 F-04는 "유지"를 정답으로 반환하는데(차별점 ②), 그 사용자를 분모에 넣으면 **정직하게 유지를 권할수록 점수가 떨어진다. 잘하면 점수가 내려가는 지표는 지표가 아니다.**

### 2-3. 왜 3층이 아니라 4층인가 — Blind-spot 층 신설

표준 Metric Tree는 **North Star · Input · Guardrail** 3층이다. 한 층을 더 뒀다.

**우리 North Star는 "골랐는지"까지만 재기 때문이다.** 신은서(해지 3회 시도, 0회 성공)는 조합안을 선택했으니 **선택률에서 성공으로 집계**된다. 실제로는 아무것도 바뀌지 않았는데도.

| 층 | 왜 안 맞나 |
| --- | --- |
| Input | Input은 **올리려고** 재는 것이다. 실행 완주율은 **올릴 수단이 없다** — 대행 권한이 없다 |
| Guardrail | Guardrail은 **넘으면 멈추는** 선이다. 실행 완주율이 낮다고 서비스를 멈출 수는 없다 — **우리 결함이 아니라 시장의 마찰**이다 |
| **Blind-spot** | **개선하지도, 중단하지도 않지만 반드시 봐야 하는 것.** North Star가 놓치는 실패를 드러내는 유일한 장치 |

> **목표값을 두지 않은 이유** — 개선할 수단이 없는데 목표를 걸면 못 지킬 약속이다. **무응답을 미완주로 세는 이유** — 이 지표는 자랑용이 아니라 **우리 스스로를 반박하는 용도**라, 좋게 나올 자유도를 일부러 없앴다.
