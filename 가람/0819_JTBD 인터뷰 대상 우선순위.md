# JTBD 인터뷰 대상 우선순위 검증 — 미래지출 결제설계 서비스

> `가람/0819_JTBD 분석 방법론.md`(참가자 모집 3그룹)이 실제로 아래 두 기준을 빠짐없이 반영했는지 검증한 결과입니다. 방법론 문서 자체는 재사용 가능한 순수 템플릿으로 유지하고, 이 문서에 "누구를, 어떤 순서로, 어디에 무게를 실어" 인터뷰할지의 구체적 판단만 담습니다.
>
> **검증 기준**
> 1. 페르소나 스펙트럼 중 핵심+확장 사용자 그룹의 Pain/Goal
> 2. AOS·DOS 점수 사분면 중 혁신기회 + 니치마켓

## 1. 검증 ① — 핵심+확장 사용자 그룹의 Pain/Goal이 빠짐없이 들어갔는가

핵심+확장 그룹은 Core 5명(이서연·김도윤·박서준·한지민·최유리) + Adjacent 3명(정하늘·오세훈·강민재) = 8명입니다. `가람/0819_AOS 분석 결과.md` 1절의 6개 후보(A~F)는 이 8명의 Pain/Goal 24건을 병합해 만든 것이므로, 8명의 Pain/Goal은 후보 A~F 어딘가에 이미 전원 반영돼 있습니다.

아래 2절에서 추려낸 우선 인터뷰 대상(A·C·F)의 기여 페르소나를 합치면:

- A(미래지출연결): 이서연·김도윤·한지민·최유리·정하늘
- C(실행완주): 이서연·박서준
- F(이벤트비종속): 오세훈·강민재

→ 합집합 = 이서연·김도윤·박서준·한지민·최유리·정하늘·오세훈·강민재 = **8명 전원**. 핵심+확장 그룹 Pain/Goal 커버리지는 결손 없이 충족됩니다.

## 2. 검증 ② — AOS·DOS 사분면 중 혁신기회+니치마켓 후보가 반영됐는가

| 기준 | 근거 문서 | 해당 후보 |
| --- | --- | --- |
| AOS 혁신기회(Q1) | `가람/0819_AOS 분석 결과.md` 5절 | **A·C·F** (Importance≥중앙값, Satisfaction<중앙값) |
| DOS 니치(SOM·SAM 두 버전 모두) | `가람/0819_AOS-DOS 혼합 매트릭스.md` | **F**만 해당 (A·C는 두 버전 모두 최우선, B는 시장주도, D·E는 후순위) |

혁신기회(A·C·F) ∪ 니치(F) = **{A, C, F}**.

`가람/0819_JTBD 분석 방법론.md`의 참가자 모집 그룹은 페르소나 8명을 이미 전원 포함하고 있어 명단 자체는 커버돼 있었지만, 이 문서가 새로 판단하는 것은 **누구를 먼저·더 깊게 인터뷰할지의 순서**입니다.

DOS가 SOM/SAM 두 버전으로 확장되면서 **A와 C 사이의 순위 관계가 모수에 따라 뒤바뀝니다.** SOM 버전(낙관적 도달가능성)은 A(3.04)>C(3.00), SAM 버전(보수적 도달가능성)은 C(2.40)>A(2.32)입니다 — 즉 A·C는 어느 모수를 쓰든 근소한 차이라 **우열을 매길 근거가 없습니다.**
