## 2-1. Core — 핵심 사용자 5명

### 이서연 (32세·대기업 마케팅팀 대리)

**1-1. 워밍업**

1. 결혼 준비하면서 이것저것 알아볼 시간도 없었는데, 지출 입력하니까 바로 카드 조합이 나오는 게 신기했어요. "이거 진작 있었으면 좋았겠다" 싶었어요.
2. 미래 지출 입력 화면에서요. 뱅크샐러드는 항상 과거 내역만 보여줬는데, 여기는 "앞으로 쓸 돈"을 물어보니까 저를 위한 서비스 같다는 느낌이 딱 왔어요.

**1-2. 단계별 체험 확인**

- 마이데이터 연동: 카드 목록이 자동으로 뜨는 건 편했는데, 솔직히 "이 정보 다 가져가도 되나" 하는 생각이 잠깐 스치긴 했어요. 그래도 결혼 준비로 바빠서 깊게 고민할 시간은 없었어요.
- 미래 지출 입력: 예식장 잔금, 혼수 견적 대충은 알고 있어서 어렵진 않았어요. 근데 정확한 금액은 아니라서 "이 숫자가 맞나" 싶긴 했어요.
- 제약조건 입력: 지금 쓰는 카드가 3장이라 딱히 어렵지 않았어요.
- 결과 화면: 제일 먼저 "그래서 총 얼마 더 받는데?"부터 봤어요. 숫자부터 확인하는 편이라.
- 해지·유지·신규: 셋을 한꺼번에 보여주니까 오히려 "이거 다 해야 되나" 살짝 부담스러웠는데, 나쁘진 않았어요.
- 계산 근거: 근거 화면 펼쳐봤는데 솔직히 다 이해는 못 했지만, "숨기지 않고 보여준다"는 것 자체가 신뢰가 갔어요.

**1-3. 기존 경험과의 비교**

1. 뱅크샐러드 카드추천 보고 카페에서 후기 찾아보는 식으로 했었어요.
2. 뱅크샐러드는 과거 소비 기준이라 결혼 준비하는 지금 상황이랑 안 맞았는데, 여기는 앞으로 쓸 돈 기준이라 훨씬 와닿았어요. 다만 카페 후기처럼 "진짜 써본 사람 얘기"가 없어서 그 부분은 아쉬웠어요.
3. 정보가 너무 많아서 뭘 봐야 할지 몰랐던 게 제일 불편했는데, 결론부터 보여주니까 그 점은 해결된 것 같아요.

**1-4. 습관**

1. 카페 후기 찾아보는 습관은 계속 할 것 같아요. 근데 계산 자체는 여기로 옮길 것 같아요.
2. 엑셀은 원래 안 썼고, 카페 검색하는 시간은 확실히 줄일 것 같아요.

**1-5. 불안 요소**

1. 아까 말씀드린 것처럼 정보 제공 동의할 때 살짝 망설였어요. 근데 결혼 준비 때문에 급해서 그냥 넘어갔어요.
2. 미래 지출은 대충이라도 알고 있어서 크게 부담은 안 됐어요.
3. 실제로 해지하러 갈 때 상담사가 자꾸 다른 카드 권할까봐 그게 제일 걱정돼요.

**1-6. 종합 판단**

1. 바꿀 것 같아요. 지금처럼 결혼 준비로 바쁠 때 시간을 제일 아껴주니까요.
2. 계산 근거를 좀 더 쉬운 말로 설명해줬으면 좋겠어요. 용어가 좀 어려웠어요.
3. 신혼여행 비용도 같이 계산에 들어가는 건지 궁금했어요.

**2절 개별 문항**

1. 네, 저희가 실제로 쓸 금액이랑 거의 비슷했어요. 예식장·스드메·혼수 다 넣으니까 얼추 맞더라고요.
2. 네, 사실 그거 걱정돼서 물어보신 거 맞죠? 예전에 콜센터 전화하면 다른 카드 권유받는다는 얘기 들어서, "이것도 그럴까" 싶었어요.
3. 확실히 달랐어요. 뱅크샐러드는 항상 "지난달에 이렇게 쓰셨네요"였는데 여기는 "앞으로 이렇게 쓰실 거니까"라서 지금 제 상황에 훨씬 맞았어요.

### 김도윤 (30세·스타트업 PM)

**1-1. 워밍업**

1. 결혼이랑 이사가 겹쳐서 정신없었는데, 한 화면에서 다 보여주니까 "아, 이게 필요했던 거였구나" 싶었어요.
2. 결혼+이사 지출을 같이 입력하는 화면 봤을 때요. 저 같은 상황을 아는구나 싶었어요.

**1-2. 단계별 체험 확인**

- 마이데이터 연동: 익숙해서 금방 했어요, 특별히 걸리는 거 없었어요.
- 미래 지출 입력: 결혼 지출이랑 이사 지출을 따로 입력했는데, 두 개를 각각 넣어야 하는 게 살짝 번거롭긴 했어요.
- 제약조건 입력: 카드 몇 장까지 쓸지 정하는 건 명확해서 좋았어요.
- 결과 화면: 결혼이랑 이사 지출을 합쳐서 하나의 조합으로 딱 정리해준 게 제일 좋았어요.
- 해지·유지·신규: 한 번에 다 보여주니까 뭘 먼저 해야 할지도 자연스럽게 이해됐어요.
- 계산 근거: 근거 항목이 잘 정리돼 있어서 저는 괜찮았어요, PM이라 이런 표 보는 데 익숙해서요.

**1-3. 기존 경험과의 비교**

1. 개인 엑셀에 카드별 실적을 수기로 추적했어요.
2. 엑셀은 제가 직접 다 업데이트해야 했는데, 여기는 자동으로 계산해주니까 그 시간이 확 줄었어요. 다만 엑셀에서는 제가 원하는 대로 커스텀할 수 있었는데 그 자유도는 좀 아쉬웠어요.
3. 여러 이벤트 겹칠 때 따로 계산해야 하는 게 제일 귀찮았는데, 그건 확실히 해결됐어요.

**1-4. 습관**

1. 엑셀 양식을 몇 년째 써와서 정이 들었는데, 계산 자체를 자동으로 해주면 굳이 고집할 이유는 없을 것 같아요.
2. 엑셀 업데이트하는 습관은 그만두게 될 것 같아요.

**1-5. 불안 요소**

1. 저는 데이터 다루는 일 해서 마이데이터 연동 자체는 크게 불안하지 않았어요.
2. 입력 자체는 어렵지 않았어요, 정확한 숫자는 아니어도 대략은 알고 있으니까요.
3. 해지 절차보다는, 계산이 실제로 맞을지가 더 걱정됐어요.

**1-6. 종합 판단**

1. 바꿀 것 같아요. 이벤트 여러 개 겹칠 때 통합해서 보여주는 게 제일 큰 이유예요.
2. 결혼이랑 이사 지출을 따로 입력해야 했던 부분이 아쉬웠어요.
3. 이벤트 끝난 뒤에 계속 쓸 이유가 있을지가 궁금했어요.

**2절 개별 문항**

1. 완전히 하나로 통합되진 않고, 따로 입력해야 하는 부분이 있어서 반은 통합, 반은 따로라는 느낌이었어요.
2. 결과 화면에서는 실행 순서가 명확했어요 — 뭘 먼저 해야 하는지 번호로 정리해줘서 좋았어요.

### 박서준 (34세·중소기업 영업직)

**1-1. 워밍업**

1. 계산 근거를 다 보여주는 게 인상 깊었어요. 예전에 카드사에서 설명 들을 때랑 너무 달라서요.
2. 근거 공개 화면 보면서요. "이 서비스는 뭔가 숨기는 게 없구나" 싶었어요.

**1-2. 단계별 체험 확인**

- 마이데이터 연동: 처음엔 좀 꺼려졌는데, 어차피 카드사도 다 알고 있는 정보라 생각하니 괜찮았어요.
- 미래 지출 입력: 큰 지출 위주로 대충 입력했어요, 어렵진 않았어요.
- 제약조건 입력: 특별히 걸리는 건 없었어요.
- 결과 화면: 추천 카드가 왜 그 카드인지부터 확인했어요, 예전에 자동대체 겪어봐서요.
- 해지·유지·신규: 해지 대상이 명확히 나와서 좋았어요.
- 계산 근거: 여기가 제일 중요했어요, 꼼꼼히 봤어요. 숫자가 어디서 나온 건지 다 나와 있어서 믿음이 갔어요.

**1-3. 기존 경험과의 비교**

1. 카드사 콜센터에 전화해서 상담받았어요.
2. 콜센터는 설명이 상담사마다 달라서 헷갈렸는데, 여기는 화면에 근거가 딱 나와 있으니까 훨씬 나았어요.
3. 설명이 상충되는 게 제일 불편했는데, 그 부분은 해결된 느낌이에요.

**1-4. 습관**

1. 콜센터 전화하는 습관은 이제 안 할 것 같아요, 여기 근거가 더 명확해서요.
2. 카드사 안내 문자만 보고 판단하던 것도 그만둘 것 같아요.

**1-5. 불안 요소**

1. 처음엔 살짝 그랬는데 어차피 카드사도 아는 정보라 크게는 아니었어요.
2. 미래 지출 입력은 부담 없었어요.
3. 이게 제일 걱정돼요 — 계산은 맞아도 실제로 해지하러 가면 또 예전처럼 다른 카드 권유받을까봐요.

**1-6. 종합 판단**

1. 바꿀 것 같아요. 근거를 다 보여주는 게 제일 큰 이유예요.
2. 해지 실행 단계에서 실제로 어떻게 도와주는지가 좀 더 구체적이었으면 좋겠어요.
3. 자동대체 안내를 받았을 때 이 서비스로 바로 비교할 수 있는 기능이 있으면 좋겠어요.

**2절 개별 문항**

1. 훨씬 신뢰가 갔어요. 자동대체 안내는 왜 그렇게 되는지 설명이 없었는데, 여기는 근거가 다 있어서요.
2. 네, 솔직히 걱정돼요. 계산은 맞는데 실제로 전화하면 또 다른 카드 권유받을까봐. 그 부분만 확실하면 완전히 믿을 것 같아요.

### 한지민 (36세·프리랜서 번역가)

**1-1. 워밍업**

1. 소득이 매달 달라지는 제 상황을 물어봐 주는 것 자체가 신기했어요.
2. 제약조건 입력할 때 카드 조합을 "이사 기간만" 임시로 바꾸는 게 가능해 보였을 때요.

**1-2. 단계별 체험 확인**

- 마이데이터 연동: 편했어요, 별다른 거부감 없었어요.
- 미래 지출 입력: 가전·인테리어 지출은 대충 알겠는데, 이번 달 소득이 얼마일지는 확실하지 않아서 입력하면서 좀 망설였어요.
- 제약조건 입력: 이 부분에서 조금 헤맸어요, 제 소득 변동성을 어떻게 반영해야 할지 몰랐어요.
- 결과 화면: 이사 기간 한정으로 조합이 바뀌는 게 나오는지부터 봤어요.
- 해지·유지·신규: 나쁘지 않았는데, 제 상황(프리랜서)이 얼마나 반영됐는지는 확신이 안 섰어요.
- 계산 근거: 근거는 잘 보여줘서 좋았어요.

**1-3. 기존 경험과의 비교**

1. 카드고릴라에서 스펙만 비교하고 실행은 감으로 결정했어요.
2. 감으로 결정하던 것보다는 훨씬 근거가 있어서 나았어요. 다만 소득 불확실성까지는 완전히 반영이 안 된 것 같아서 그 부분은 아쉬웠어요.
3. 스펙만 보고 실제로 맞는지 확신이 없었던 게 불편했는데, 근거를 보니 좀 나아졌어요.

**1-4. 습관**

1. 카드고릴라에서 스펙 비교하는 습관은 아마 완전히 없애기는 어려울 것 같아요, 확인차 계속 볼 것 같아요.
2. 감으로 결정하던 건 그만둘 것 같아요.

**1-5. 불안 요소**

1. 크게 불안하진 않았어요.
2. 소득이 확실하지 않은 상태에서 입력하는 게 좀 걱정됐어요. "이 숫자가 틀리면 어떡하지" 싶었어요.
3. 해지·전환 자체보다는 계산이 제 상황에 맞을지가 더 걱정됐어요.

**1-6. 종합 판단**

1. 바꿀 것 같긴 한데, 소득 변동 반영이 더 확실해지면 완전히 믿을 것 같아요.
2. 소득 불확실성을 반영하는 방법이 좀 더 명확했으면 좋겠어요.
3. 이사 끝나고 원래대로 되돌리는 절차가 얼마나 간단한지 궁금했어요.

**2절 개별 문항**

1. 어느 정도는 반영되는 느낌이었는데, 확실하진 않았어요. 단일 숫자로만 입력해야 한다고 느꼈으면 꽤 부담됐을 것 같아요.
2. 화면상으로는 가능해 보였는데, 실제로 얼마나 간단할지는 직접 해봐야 알 것 같아요.

### 최유리 (39세·대기업 회계팀 과장)

**1-1. 워밍업**

1. 계산 과정을 다 보여주는 게 좋았어요, 저는 숫자를 검증하는 게 습관이라서요.
2. 계산 근거 화면에서요, 회계 하는 사람 눈에도 나쁘지 않다 싶었어요.

**1-2. 단계별 체험 확인**

- 마이데이터 연동: 익숙해서 괜찮았어요.
- 미래 지출 입력: 발령 이후 바뀔 지출을 입력했는데, 예상 범위로 넣을 수 있어서 편했어요.
- 제약조건 입력: 명확했어요.
- 결과 화면: 숫자 먼저 확인하고, 바로 근거 화면으로 넘어갔어요.
- 해지·유지·신규: 논리적으로 이해가 됐어요.
- 계산 근거: 여기를 제일 오래 봤어요. 항목별로 다 뜯어봤는데, 제가 직접 엑셀로 하던 검증 방식이랑 비슷한 구조였어요.

**1-3. 기존 경험과의 비교**

1. 제가 직접 엑셀로 시뮬레이션했어요, 시간이 오래 걸려서 자주 포기했었고요.
2. 시간이 확실히 줄었어요. 다만 제가 직접 만든 건 아니라서 완전히 믿으려면 근거를 좀 더 깊이 봐야 할 것 같긴 해요.
3. 시간이 오래 걸리는 게 제일 문제였는데, 그건 확실히 해결됐어요.

**1-4. 습관**

1. 엑셀로 직접 검증하던 습관은 완전히 버리진 못할 것 같아요, 그래도 크로스체크 용도로는 계속 쓸 것 같아요.
2. 처음부터 끝까지 수작업으로 시뮬레이션하던 건 그만둘 것 같아요.

**1-5. 불안 요소**

1. 크게 없었어요.
2. 미래 지출은 예상 범위로 넣을 수 있어서 부담 없었어요.
3. 특별한 불안은 없었어요, 오히려 계산이 정말 맞는지가 더 궁금했어요.

**1-6. 종합 판단**

1. 바꿀 것 같아요. 시간을 아껴주는 게 제일 커요.
2. 계산 근거를 더 세부적으로(예: 원 단위 산출 과정) 볼 수 있으면 좋겠어요.
3. 다음 변화가 생겨도 이 서비스가 계속 신뢰할 만할지, 그게 제일 궁금해요.

**2절 개별 문항**

1. 투명하다고 느꼈어요. 다만 제가 회계 일을 해서 그런지, 세부 산출 근거를 한 단계 더 파고들고 싶은 부분은 있었어요.
2. 네, 확실히 시간을 줄여준다고 느꼈어요. 제가 직접 하면 반나절은 걸렸을 걸 몇 분 만에 봤으니까요.

## 2-3. Extreme — 극단 사용자 2명 (그룹 B: 최근 이탈)

2. 완전히 확신은 안 서요. 계산은 더 명확해졌지만, 예전에 3번이나 실패해서 이번엔 다를 거라는 보장이 있어야 할 것 같아요 — 예상 만류 포인트랑 대응법이 같이 있으면 좋겠어요.

3. 20장 넘게 정리하려면 시간이 얼마나 걸릴지, 그게 걱정됐어요.

**1-6. 종합 판단**

1. 써보고는 싶은데, 한 번에 다 보여주는 방식이면 또 미룰 것 같아요.
2. 정보량을 줄여서 조금씩 보여줬으면 좋겠어요.
3. "이번 주엔 이것만 하세요" 이런 식으로 나눠줄 수 있는지 궁금했어요.

**2절 개별 문항**

1. 우선순위는 명확하게 나왔는데, 그래도 20장이 넘으니까 화면 자체가 부담스럽게 느껴졌어요.
2. 단계적으로 나눠서 보여주는 쪽이 훨씬 실행하기 쉬울 것 같아요. 한 번에 다 보면 그냥 미루게 돼요.

## 2-4. Non-user — 비활성 사용자 2명 (그룹 C: 미인지)

### 조민아 (26세·프리랜서)

**1-1. 워밍업**

1. 몇 달 뒤 지출을 입력하라니까 "이걸 내가 어떻게 알아" 싶었어요.
2. 미래 지출 입력 화면에서요, 그때부터 좀 회의적으로 봤어요.

**1-2. 단계별 체험 확인**

- 마이데이터 연동: 앱은 익숙해서 어렵지 않았어요.
- 미래 지출 입력: 여기가 제일 힘들었어요, 몇 달 뒤를 예측해서 입력하라니까 억지로 대충 아무 숫자나 넣었어요.
- 제약조건 입력: 크게 어렵진 않았어요.
- 결과 화면: 나온 숫자 자체가 제가 대충 입력한 값 기반이라 크게 믿음이 안 갔어요.
- 해지·유지·신규: 그냥 훑어봤어요.
- 계산 근거: 근거는 봤는데, 애초에 입력값이 부정확하니까 의미가 없다고 느꼈어요.

**1-3. 기존 경험과의 비교**

1. 지인이 추천한 카드 1장만 계속 쓰고 있어요.
2. 최적화 자체를 안 하고 살아서, 이 정도로 세밀하게 계산해주는 게 낯설었어요. 근데 입력값 자체가 부정확하니 크게 와닿지는 않았어요.
3. 특별히 불편한 게 없었어서 비교하기가 좀 어려웠어요.

**1-4. 습관**

1. 지인 추천 카드 1장만 쓰는 습관, 그게 제일 걸림돌이에요.
2. 딱히 그만둘 것 같지 않아요.

**1-5. 불안 요소**

1. 딱히 없었어요.
2. 이게 제일 커요 — 몇 달 뒤를 어떻게 미리 아냐는 생각이 계속 들었어요.
3. 애초에 해지·전환할 계획이 없어서 불안하지 않았어요.

**1-6. 종합 판단**

1. 지금은 안 바꿀 것 같아요. 예측 자체가 와닿지 않아서요.
2. 입력하는 수고에 비해 얻는 게 크게 느껴지지 않았어요.
3. 예측 말고 그냥 지금 상황 보고 판단해주는 방식이면 다시 볼 것 같아요.

**2절 개별 문항**

1. 솔직히 여전히 들었어요. "이걸 어떻게 미리 아냐"는 생각이 입력하는 내내 있었어요.
2. 아니요, 수고에 비해 가치가 크게 느껴지지 않았어요. (E-05 "가장 큰 가정" 검증 — 부정적)
3. 네, 그런 방식이면 훨씬 써보고 싶을 것 같아요. 예측 안 해도 되니까요.

### 배정호 (62세·자영업자)

**1-1. 워밍업**

1. 화면에 입력할 게 많아서 어디서부터 해야 할지 몰랐어요.
2. 처음 시작 화면 봤을 때부터 좀 낯설었어요.

**1-2. 단계별 체험 확인**

- 마이데이터 연동: 이 단계부터 어려웠어요, 뭘 동의하는 건지 잘 모르겠더라고요.
- 미래 지출 입력: 거의 못 했어요, 뭘 넣어야 할지 몰랐어요.
- 제약조건 입력: 그냥 넘어갔어요.
- 결과 화면: 숫자가 많아서 잘 안 들어왔어요.
- 해지·유지·신규: 이해하기 어려웠어요.
- 계산 근거: 안 봤어요, 이미 지쳐서요.

**1-3. 기존 경험과의 비교**

1. 종이 가계부 쓰고, 궁금한 건 은행 창구 가서 물어봐요.
2. 창구에서는 사람이 직접 설명해주는데, 여기는 저 혼자 화면 보고 알아내야 해서 훨씬 어려웠어요.
3. 딱히 불편한 게 없어서 비교가 잘 안 돼요, 저는 지금 방식이 편해요.

**1-4. 습관**

1. 종이 가계부 습관은 그대로 갈 것 같아요, 앱 자체가 낯설어서요.
2. 은행 창구 가는 것도 계속할 것 같아요.

**1-5. 불안 요소**

1. 네, 뭘 동의하는 건지 몰라서 불안했어요.
2. 입력 항목이 많아서 그냥 앱을 닫고 싶었어요.
3. 저는 신용카드를 잘 안 써서 해지·전환 자체가 저랑 상관없다고 느꼈어요.

**1-6. 종합 판단**

1. 안 바꿀 것 같아요. 지금 방식이 저한테는 큰 불편이 없어서요.
2. 처음부터 끝까지 입력이 많은 게 제일 아쉬웠어요.
3. 입력 없이 바로 결과부터 보여주는 화면이 있으면 다시 볼 의향은 있어요.

**2절 개별 문항**

1. 마이데이터 연동 화면부터 이해가 안 됐고, 특히 미래 지출 입력 화면에서 제일 막막했어요.
2. 네, 그런 화면이 있으면 한번 눌러보고는 싶을 것 같아요.
3. 사실 잘 못 느껴요. 지금도 체크카드·현금으로 큰 불편 없이 지내고 있어서요.
