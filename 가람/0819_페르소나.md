# 페르소나 (방법론 05) — 미래지출 결제설계 서비스

> Market Segment Map(`윤정/0818_쟁점정리.md` 쟁점3, `효진/TAM-SAM-SOM 정의 작업안.md`)이 정의한 고객 그룹 유형(Q1~Q4, SAM Phase1/Phase2)으로부터 페르소나를 추출했습니다. 방법론 5장 연결 규칙("TAM-SAM-SOM → Segment Map → Persona가 같은 세그먼트를 가리키는가")에 따라, Segment Map에서 실제 타겟으로 판정된 그룹만 페르소나로 구체화하고 제외 그룹은 사유만 남깁니다.
>
> 표기: 🔵 Fact · ⚪ Inference · 🟡 Assumption · 🟠 미확인 — `방법론.md` 8장 기준

## 1. 페르소나 A — 혼인(신혼) 예비자 [Q1 · 1차 표적/SOM]

| 항목 | 내용 |
| --- | --- |
| 유형명 | 카드 재설계 신혼러 |
| 역할 | 결제수단을 스스로 선택할 수 있는 개인 신용카드 실사용자 중, 1~3개월 내 혼인으로 고액 지출이 예정된 당사자(배우자와 공동 지출 계획을 조율하는 입장) |
| 주요 문제 | 신혼여행·혼수·웨딩패키지 등 지출이 짧은 기간에 몰리는데(1인당 1,473~2,203만원, 🔵 E-03~E-06), 카드별 전월실적 구간·혜택한도·연회비 조건이 복잡해 스스로 최적 조합을 계산하지 못함. 기존 서비스(뱅크샐러드 등)는 과거 소비 기준 단일 카드 추천에 그쳐 미래 지출 변화를 반영하지 못함 |
| 목표 | 결혼 준비 기간의 지출 변화에 맞춰 보유·신규 카드 조합을 재설계해 놓치는 혜택 없이 최대 혜택을 받는 것. 카드사의 일방적 자동대체·해지 유도에 끌려가지 않고, 스스로 검증 가능한 근거로 결정을 내리는 것 |
| 사용 맥락 | 웨딩업체 계약~예식 전후 1~3개월. 혼수·여행 등 카테고리별 예상 지출액을 직접 입력하고, 카드별 시나리오 비교 결과를 확인·조정하는 의사결정 순간에 집중적으로 사용 |
| Segment Map 근거 | Trigger 감지가능성 높음(웨딩업체 신호로 감지 용이) · 1인당 지출강도 최고 — Q1~Q4 중 유일한 1차 표적(SOM) |

## 2. 페르소나 B — 입주(이사) 예정자 [Q2 · 2차 리서치 대상]

| 항목 | 내용 |
| --- | --- |
| 유형명 | 이사 시즌 카드 재배치 고민러 |
| 역할 | 전입·이사를 앞두고 가전·인테리어 등 목돈 지출이 예상되는 신용카드 실사용자(세대주 또는 계약 당사자) |
| 주요 문제 | 이사 시점에 가전·인테리어·중개수수료 등 일시적 고액지출이 몰리지만, 부동산 중개 채널이 파편화돼 있어 트리거 감지가 어렵고(낮음), 지출 시점과 카드 혜택 조건이 맞물리지 않아 최적 조합을 판단하기 어려움 |
| 목표 | 이사 준비 기간 동안 늘어나는 지출에 맞춰 카드 혜택을 최대화하고, 이사가 끝나 소비 패턴이 원래대로 돌아갈 때 조합을 다시 되돌릴 수 있는 유연한 결제 설계 |
| 사용 맥락 | 이사 계약 체결~입주 전후 1~3개월. 가전·인테리어 구매가 몰리는 시점에 카테고리별 지출 변화를 입력해 카드 재배치 시나리오를 확인 |
| Segment Map 근거 | Trigger 감지가능성 낮음(부동산 중개 파편화) · 1인당 지출강도 🟠 미확인 — 강도 데이터 확보 시 Q1을 능가할 가능성이 있어 우선 리서치 대상(Q1 다음 순위) |

## 3. 페르소나 C — 이벤트 비종속 소비변화 관리자 [SAM Phase 2 · 확장 세그먼트]

| 항목 | 내용 |
| --- | --- |
| 유형명 | 자율 소비변화 관리자 |
| 역할 | 혼인·이사 같은 특정 생애 이벤트 없이도, 이직·자녀 독립·은퇴·유학 준비 등으로 스스로 소비 구조 변화를 인지하고 대응하려는 신용카드 실사용자. 제품 로직상 이벤트 종류를 특정하지 않는 일반 사용자군 |
| 주요 문제 | 소비 패턴이 바뀌는 원인이 사람마다 달라(이직으로 인한 소득·지출 변화, 자녀 독립으로 인한 생활비 축소, 은퇴·유학으로 인한 지출 감소 등) 공통 채널로 도달하기 어렵고, 카드별 혜택 조건 변화에 스스로 대응하기 힘듦. 특히 은퇴·유학처럼 소비가 "감소"하는 경우는 지출 증가를 가정한 기존 설계와 방향이 반대라 별도 설계가 필요 |
| 목표 | 특정 이벤트 여부와 무관하게, 스스로 입력한 미래 소비 변화값을 근거로 카드 조합을 재계산받아 실행 가능한 Payment Plan을 확보하는 것 |
| 사용 맥락 | Beachhead(혼인) 검증 이후 제품 로직이 일반화된 단계에서, 특정 생애 이벤트 없이 카테고리별 지출 변화를 자율적으로 입력하는 시나리오 |
| Segment Map 근거 | TAM-SAM-SOM 구조상 SAM Phase 2(이벤트 비종속 확장) ⚪ 추정 — 아직 실측 세그먼트 데이터 없음, 쟁점 2("이벤트 비종속" 제품 로직 결정)가 근거 |

## 4. 페르소나로 구체화하지 않은 세그먼트

| 세그먼트 | 사유 |
| --- | --- |
| Q3. 해외여행(일반) | Trigger 감지가능성 낮음(OTA 제휴 필요) + 1인당 지출강도 낮음(1건당 약 102만원) — Segment Map에서 "대상 아님"으로 판정. 단, 신혼여행(1,030만원, 일반 해외여행의 약 10배)은 페르소나 A(Q1)에 포함되는 고강도 항목 |
| Q4. 카드 갱신 일반군 | Trigger 감지가능성은 매우 높지만(카드사 자체 데이터) 1인당 지출강도가 낮고 무차별 대상 — Segment Map에서 "대상 아님"으로 판정, 세그먼트가 아니라 향후 채널 후보로만 남김 |

> ⚠️ Q1~Q4·SAM Phase2는 현재 리서치로 데이터를 확보할 수 있었던 그룹일 뿐입니다. 자녀 입학 등 다른 JTBD 유발 이벤트가 추가로 존재할 수 있으며, 신규 세그먼트 데이터가 확보되면 이 문서에 페르소나를 추가합니다.
