## 0. 통합 앵커 — 한 문장 문제정의

Master Deck 전체가 이 문장에서 역산됩니다. `방법론.md` 5장 연결규칙상 모든 페이지가 이 문장으로 역추적되어야 합니다(p13~14가 이 문장의 정식 자리).

> **소비 구조가 바뀔 예정인 신용카드 사용자는 바뀐 지출에 맞게 카드 조합을 다시 짜고 싶지만, 전월실적 구간·혜택한도·연회비가 얽혀 스스로 계산할 수 없고, 기존 카드추천은 과거 소비 데이터만 보며, 계산이 맞아도 해지·전환 실행에 마찰이 커서 — 결국 카드사가 근거를 공개하지 않은 채 실행하는 자동대체에 자신의 결제 포트폴리오를 맡기게 된다.**

발표용 축약: *소비가 바뀔 사람은 카드 조합을 다시 짜야 하는데, 스스로 계산할 수도 없고 기존 서비스는 과거만 보기 때문에, 결국 카드사가 근거 없이 바꿔주는 대로 따라간다.*

**상태: 🟠 팀 미승인** — 07 JTBD(가람) 확정 시 최종 문구 고정. 장애물 3개가 차별점 A·B·C와 1:1 대응하도록 조립했습니다.

| 장애물 절 | 근거 | 정당화하는 차별점 |
| --- | --- | --- |
| 스스로 계산할 수 없다 | 전월실적·혜택한도·연회비 복잡성(ⓐ) — 브리프 5절 | — (문제의 토대) |
| 기존 서비스는 과거만 본다 | 경쟁 6곳 미래소비반영 전부 ✗ 🔵 / 교차도메인 2축에서도 빈칸 유지 | **B. 과거가 못 보는 소비** |
| 계산이 맞아도 실행이 안 된다 | 상담사 만류·절차 복잡 🔵 + 페르소나 신은서(제3축 실행완주율) | **A. 실행 설계자** |

## 0-1. 기준 서비스 ↔ 개선 기능 대비축

p1 표지·p3~5(경쟁)·p13~14(문제구조)·p21~23(To-Be)이 모두 이 대비를 인용합니다. 08.19 확정.

| | 기준 서비스 (As-Is) | 우리 (To-Be) |
| --- | --- | --- |
| 진입 경로 | `카드 갈아타기 > 카드 탐색 > 내 카드보다 더 좋은 카드 보기` 🔵 | 동일 지점 — 이 플로우 위에 얹음 |
| 계산 입력 | **최근 1년 소비**를 후보 카드에 재적용 🔵 (PDF 1p "핵심 구조") | **사용자가 입력한 미래 지출** + 마이데이터 과거 소비 |
| 계산 단위 | 후보 카드 **한 장**에 재적용 🔵 | **카드 조합 배분**(F-05 결제수단 배분 설계) |
| 산출물 | "대신 쓸 때 혜택 많이 받는 카드 **순위**" 🔵 | 실행 가능한 **Payment Plan** + 계산 근거 공개(F-06) |

> **개선축이 2개입니다** — ⓐ 시간축(과거 1년 → 미래 입력)과 ⓑ 조합축(한 장 → 카드 조합 배분). 브리프 3절 차별점은 B(과거가 못 보는 소비)로 ⓐ만 서술하고 ⓑ는 A(실행 설계자)에 섞여 있는데, PDF 실측으로 확인된 As-Is가 "**한 장** 재적용"이므로 ⓑ를 독립 개선축으로 분리해 쓰는 것이 방어력이 강합니다.
