# 미래지출 결제설계 서비스 — 아이디어 구체화 (한 페이지)

> 08.18(화) 체크포인트 "Question & Role Lock" 산출물. `쟁점정리.md`·`피치덱.md`·`국내 신용카드 시장 리서치.md`의 확정/근거 내용을 한 페이지로 종합했습니다. 새 주장은 추가하지 않았습니다 — 출처는 각 문서 참고.

| 항목 | 내용 |
| --- | --- |
| **기준 서비스** | 뱅크샐러드 "나에게 딱 맞는 카드 찾기" — 마이데이터 기반 카드추천 + 발급연계(2026.05 출시). 경쟁사 6곳(뱅크샐러드·카드고릴라·더쎈카드·토스·Credit Karma·NerdWallet) 중 실행설계·미래소비반영을 동시에 만족하는 곳이 없다는 것이 확인된 대표 사례로 선정. As-Is 유저플로우는 실사용 캡처로 이미 확보(`윤정/data/` 스크린샷 12장, `경쟁사_유저플로우_뱅크샐러드.pdf`) |
| **시장** | 국내 카드시장 2026년 2분기 승인실적 336.9조원(전년 +7.6%), 신한카드 1위·삼성카드와 초접전(격차 4천억원). 카드추천·비교 서비스는 카드고릴라(MAU 140만)·토스 카드라운지(방문 11배↑)·뱅크샐러드·카카오페이가 경쟁 중. 2026년 트렌드 키워드 "PIVOT"(PLCC·준프리미엄·글로벌프리미엄·선택형·트래블카드)으로 카드 조합이 다양해지며 "카드조합 전략"의 필요성이 커지는 국면 |
| **세그먼트** (TAM-SAM-SOM 투트랙) | **TAM**: 마이데이터 가입 1.77억 건(고유 약 3천만 명 추정, ⚪ 재검증 필요·INSIGHT 참고) · **SAM(초기 검증)**: 혼인·이사·출산 등 확인 가능한 생애이벤트 예정자(공식 통계 근거 확보 가능) · **SOM(제품 확장)**: 이벤트 무관, 소비 변화를 직접 입력하는 전체 사용자로 자연 확장 |
| **사용자** (Beachhead) | 신혼·입주 등 1~3개월 내 고액구매 예정 + 보유 카드 조합을 바꿔야 하는 사용자. 제품 로직 자체는 이벤트 비종속(쟁점 2) — 생애이벤트는 마케팅·초기 검증용 타겟 정의일 뿐, 기능은 카테고리별 지출 변화값 입력만 받음 |
| **문제** | ① 6개 경쟁사 중 실행설계·미래소비반영·근거공개 3조건을 동시 충족하는 곳 없음 ② 카드사의 일방적 "단종카드 자동대체" 후 혜택 불일치 민원이 실재(2022→2025 민원 88.4%↑, 유형①) — 우리가 하려는 재배치를 카드사가 이미 하고 있고 그 결과에 대한 불만이 있음 ③ 카드 해지는 계산상 맞아도 실행 마찰이 커서(상담사 만류, 절차 복잡) 기대와 실제 서비스 능력 사이 괴리 위험 |
| **기대 결과** (Value) | 사용자가 미래 소비 변화를 입력하면, 카드별 전월실적 구간·혜택한도·연회비를 반영해 **실행 가능한 결제조합(Payment Plan)을 계산 근거와 함께** 제시 → 카드사의 일방적 자동대체·해지 유도가 아니라, 사용자가 **스스로 검증 가능한 재배치 결정**을 내릴 수 있게 됨. 1차 성과지표는 Payment Plan Selection Rate(피치덱 8장) |
