## 2. 자료 접근성(Data Accessibility) 점검

| 데이터 유형 | 접근 가능 여부 | 근거/방식 | 조치 |
| --- | --- | --- | --- |
| 카드 이용내역(결제내역) | 🔵 마이데이터 API로만 제공, 오픈뱅킹 불가 | 금융위원회 보도자료 2024.12.30 | MVP는 사용자 직접 입력으로 우회 확정(쟁점 1) — 규제 문제 자체가 발생하지 않음 |
| 카드 혜택 Rule(전월실적 구간·캐시백율·통합할인한도) | 🔵 카드사 공식 약관으로 확보 가능하나 변경 잦음 | 카드고릴라·카드모아·뱅크샐러드 콘텐츠 취합 | Guardrail G-02(Stale Promotion Rate) 필요 — MVP 카드 후보군 소수(트렌드 키워드별 1~2종) 제한 |
| 경쟁사 UX(As-Is Flow) | 🔵 뱅크샐러드만 확보(캡처 12장+PDF) / 🟠 카드고릴라·토스·카카오페이·Credit Karma·NerdWallet 미확보 | 윤정 직접 캡처 | 나머지 5개 경쟁사는 공식 화면·도움말로 추가 확보 필요(문제·메커니즘 리서치 담당과 분담 검토) |
| 시장·규제 통계 | 🔵 여신금융협회·한국은행·금융위원회·마이데이터 종합포털 공개자료 | 국내 신용카드 시장 리서치 1~6장 | 집계 기준이 다른 항목(마이데이터 이용자 수 1.77억 건 vs 1.65억 명 등)은 팀이 원자료로 재검증 필요 |
| 민원 유형별 정량 비중 | 🟠 확인 안 됨 | 금감원 발표는 유형 설명 위주, 유형별 통계 미공개 | 여신금융협회 소비자공시 또는 금감원 "금융소비자의 소리" 직접 문의 필요(우선순위 낮음 — OS 분석에 참고자료로만 사용) |
| 생애이벤트(혼인·이사) 지출 통계 | 🔵 확보(혼인 1인당 결제대상 지출 1,473~2,203만원) | 경쟁사·시장 공개자료(E-03~E-06) | SAM 근거로 사용 — 이벤트 비종속화로 이 근거가 약해지지 않는지 재확인 필요(쟁점정리 질문 8) |

**결론**: MVP 실행에 필요한 핵심 데이터(카드 혜택 Rule, 시장 통계, 기준서비스 UX)는 확보 가능하거나 이미 확보됨. 남은 공백(경쟁사 5곳 UX, 민원 유형별 비중)은 우선순위가 낮아 32시간 스코프에 영향 없음.

## 3. 문제 구조(Problem Structure) 점검

`방법론.md` 2장 형식(낮은 수준 표현 → 구조적 표현)에 맞춰 재확인했습니다.

| 낮은 수준의 표현 | 구조적으로 바꾼 표현 | 탐색 가능 영역 |
| --- | --- | --- |
| 카드 추천이 미래 소비를 반영하지 못한다 | 소비 패턴 변화가 예상되는 사용자가, 카드별 전월실적 구간·혜택한도·연회비 조건이 복잡하게 얽혀 있어 스스로 최적 카드 조합을 판단하지 못하고, 결과적으로 카드사의 일방적 자동대체·과거 소비 기준 추천에 의존하게 된다 | 조건 비교·선택지 축소(여행·보험 비교), 조건 변화 시 재계산(대환대출·통신요금제 자동전환), 자동 재배치의 근거 공개(전력 시간대 요금 최적화) |

이미 `쟁점정리.md`에 구조화된 문제 정의(F-01~F-06, 차별점 A·B·C)가 있어 별도 재작업은 불필요 — 이번 점검은 **기존 정의가 기능명이 아니라 문제 구조 수준으로 서술되어 있는지 확인**하는 절차였고, 통과로 판정합니다.

| 02 | 가치사슬 | 🟠 미착수 | 핵심 활동·가치·병목·개선기회 맵 1장 | 카드사 활동은 자료 있으나, "카드추천 플랫폼"으로서 우리 서비스 자체의 가치사슬은 신규 작성 |

| 06 | 기회점수(OS) | 🟠 미착수 | 요구 5~10개 중요도·만족도·OS 우선순위 | 민원 4유형(연회비 환급 오해·리볼빙 인지부족 등)이 좋은 출발점 |

| 08 | Value Proposition Sheet | 🔵 부분 있음(피치덱 차별점 A·B·C) | Customer Profile + Value Map + 선언문 | 06·07 산출물을 입력받아 정식 포맷으로 재정리 |
| 09 | PRD | 🔵 부분 있음(F-01~F-06, Out-of-Scope) | 목적·범위·시나리오·요구사항·AC·KPI·리스크 | 쟁점정리 질문 5~9(입력단위, 혜택Rule 갱신, 일회성/지속형, 규제리스크)를 AC·Guardrail로 흡수 |
