# Porter's Five Forces

| 힘 | 강도 | 판단 근거 |
| --- | --- | --- |
| 신규 진입 위협 | 중간~낮음 | 계산 엔진 자체는 규칙 기반 소프트웨어라 기술 장벽이 낮다. 다만 마이데이터 데이터 접근권이 실질적 진입장벽이며, 카드사 혜택 규정을 지속적으로 추적·갱신해야 하는 데이터 운영 비용이 후발주자에게도 동일하게 적용된다. |
| 대체재 위협 | 높음 | "지금 카드를 그대로 쓴다"는 선택이 가장 강력한 대체재다. 카드사가 이미 단종카드 자동대체로 재배치를 대신 수행하고 있어 사용자가 능동적 전환 필요성을 느끼기 어렵고, 무료 가계부·지인 추천·커뮤니티 조언도 대체 경로로 작동한다. |
| 공급자 교섭력 | 높음 | 카드 결제내역은 마이데이터 API로만 제공되며 오픈뱅킹으로는 제공되지 않아 데이터 채널이 사실상 하나뿐이다. 마이데이터 본허가 사업자는 69개사로 제한돼 있고, 카드 혜택 규정(전월실적 구간·통합할인한도 등)은 통합 API 없이 카드사별 약관에 파편화돼 있다. API 이용료는 사용량에 비례해 늘어나는 구조라 사용자가 늘수록 원가 부담도 커진다. |
| 구매자(사용자) 교섭력 | 높음 | 카드고릴라·뱅크샐러드·토스·카카오페이 등 무료 대안이 이미 다수 존재하고, 가입비·데이터 이전 비용이 없어 전환비용이 사실상 0에 가깝다. |
| 기존 경쟁 강도 | 중간~높음 | 카드고릴라(MAU 약 140만)·뱅크샐러드(카드추천 이용자 약 130만 명)·토스·카카오페이가 모두 마이데이터 기반 카드추천 경쟁을 벌이고 있다. 다만 미래 소비 반영·다중카드 조합 재배치·계산 근거 공개를 동시에 제공하는 곳은 없다 — 가장 앞선 뱅크샐러드도 과거 1년치 소비 기준, 단일 카드 비교, 신규 발급 연계에서 끝난다. |

## 종합 판단

구매자 힘과 대체재 위협이 강해 사용자 유입·유지가 쉽지 않고, 공급자(마이데이터·카드데이터) 의존도가 높아 데이터 운영 비용과 리스크가 존재하는 시장이다. 다만 경쟁자 대부분이 미래소비 반영·다중카드 재배치·근거공개를 동시에 다루는 조합을 제공하지 않아, 해당 세그먼트는 상대적으로 비어 있다.
